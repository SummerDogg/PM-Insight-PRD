# 产品洞察与 PRD / Product Insight & PRD

Get the package from [GitHub](https://github.com/SummerDogg/pm-insight-prd).

## Overview

A Codex- and Claude-compatible product research and PRD plugin with 9 skills and 4 guided workflows. Read the [full bilingual guide](../README.md) for capabilities, process, installation, and usage examples.

本插件包含 9 个研究与 PRD 技能、4 个引导式工作流。功能范围、详细流程、安装方式和使用示例请阅读[中英双语指南](../README.md)。

## Installation

Use the installation method described in the [root README](../README.md). In Codex, install the plugin marketplace or copy the skill folders to `~/.codex/skills/`.

## Skills (9)

- `pm-insight-prd`
- `create-prd`
- `user-personas`
- `market-segments`
- `user-segmentation`
- `customer-journey-map`
- `market-sizing`
- `competitor-analysis`
- `sentiment-analysis`

## Commands (4)

- `/pm-insight-prd:write-prd`
- `/pm-insight-prd:research-users`
- `/pm-insight-prd:competitive-analysis`
- `/pm-insight-prd:analyze-feedback`
